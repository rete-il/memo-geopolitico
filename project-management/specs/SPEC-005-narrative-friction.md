# SPEC-005 — Fricción vs. Narrativa

**Estado:** Borrador
**Release:** Beta 3
**Work items:** FRIC-001 a FRIC-006

## Objetivo

Comparar intensidad geopolítica editorialmente evaluada con atención mediática observada, mostrando desfases relevantes sin presentar el resultado como una medición absoluta.

## Estados iniciales

- Punto ciego.
- Ruido.
- Sincrónico.
- En observación.

## Datos requeridos

- ID y título.
- Región/subregión.
- Nivel de escalada.
- Atención mediática.
- Estado calculado o editorial.
- Resumen e interpretación.
- Nivel de confianza.
- Fecha de actualización.
- Versión metodológica.
- Fuentes.

## Principios

- Primera versión manual y editorial.
- Metodología pública.
- Umbrales configurables.
- Explicación textual accesible.
- Rótulo “experimental” durante validación.

## Criterios de aceptación

- Ninguna tarjeta carece de fuente y fecha.
- Los lectores pueden entender por qué se asignó el estado.
- El módulo funciona sin depender solo de barras o color.
- Los datos demostrativos no se confunden con datos reales.
