# SPEC-001 — Arquitectura de información objetivo

**Estado:** Borrador  
**Release:** Beta 1  
**Work items:** IA-001

## Objetivo

Definir una estructura comprensible y estable para Monitor, Análisis, Ensayos, Directorio y Regiones.

## Navegación objetivo

```text
Inicio | Monitor | Análisis | Ensayos | Directorio | Regiones
```

## Reglas

- “Monitor” contiene alertas, mapa, indicadores y seguimientos.
- “Análisis” interpreta hechos actuales.
- “Ensayos” contiene textos de mayor permanencia.
- “Directorio” es una herramienta de investigación independiente.
- “Regiones” organiza datos, interpretación y contenido relacionado.

## Criterios de aceptación

- Un usuario nuevo puede explicar la diferencia entre secciones.
- No existen enlaces principales sin página índice.
- Cada tipo de contenido tiene nombre, finalidad y metadatos definidos.
- La estructura admite móvil y escritorio.

## Preguntas abiertas

- ¿“Para profundizar” desaparece como etiqueta o se conserva como CTA contextual?
- ¿“Análisis a fondo” se renombra simplemente como “Análisis”?
