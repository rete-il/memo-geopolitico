# SPEC-006 — Reorganización de portada

**Estado:** Borrador
**Release:** Beta 3
**Work items:** HOME-001, MAP-001, MAP-003

## Objetivo

Reducir competencia visual y ordenar la portada por nivel de atención.

## Jerarquía

1. Acontecimiento principal.
2. Alertas activas.
3. Mapa o lista.
4. Fricción vs. Narrativa.
5. Análisis recientes.
6. Regiones en seguimiento.
7. Ensayos.
8. Metodología y transparencia.

## Responsive

- Escritorio: mapa dominante, paneles laterales subordinados.
- Móvil: secuencia vertical; vista lista predeterminada para contenido geográfico.

## Criterios de aceptación

- El usuario identifica en pocos segundos el acontecimiento principal.
- La columna de indicadores explica metodología y fecha.
- El mapa tiene fallback textual.
- No hay módulos prototipados sin rotular.
