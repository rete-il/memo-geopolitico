# Reforma 0.6.0

## Decisión de diseño

La versión conecta dos extremos del flujo editorial:

```text
Taxonomía + catálogo de fuentes
        ↓
Generador contextual
        ↓
Investigación en ChatGPT
        ↓
Lote JSON completo
        ↓
Nuevos + actualizaciones + bloqueos
        ↓
Revisión humana, guardado y backup
```

## Normalización temática

La lista editorial de 20 entradas se separó en:

- 19 ejes configurables;
- un criterio transversal permanente.

Cada eje vincula temas, actores, señales y términos de selección de fuentes. Región y actores permanecen como dimensiones separadas.

## Actualizaciones

El macroevento se trata como expediente persistente y las señales como evolución fechada. Una coincidencia con evidencia nueva no crea otra ficha.

La actualización conserva identidad y estados, agrega evidencia seleccionada y registra trazabilidad. Los cambios sustantivos requieren aprobación campo por campo.

## Compatibilidad

- base editorial: esquema 2;
- contrato recomendado de candidatos: esquema 2;
- candidatos v1: aceptados;
- aplicación local sin dependencias externas;
- datos iniciales: 17 macroeventos.
