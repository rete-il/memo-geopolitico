Qué es esta aplicación

Dashboard local y autónomo para generar búsquedas, revisar macroeventos, incorporar su evolución y preparar encargos editoriales internos. No publica en Memo Geopolítico, no usa APIs externas y no modifica GitHub.

Expedientes públicos y encargos editoriales

Cada macroevento genera directamente un expediente público del Observatorio. Un encargo editorial es un trabajo interno y opcional para investigar o redactar una publicación a partir de uno o más macroeventos.

Flujo editorial

  1. Configurar y generar un prompt de búsqueda contextual.
  2. Ejecutarlo en ChatGPT e importar el lote JSON completo.
  3. Revisar candidatos nuevos, actualizaciones, casos sin novedad y compuestos.
  4. Aplicar las decisiones y guardar con backup.
  5. Crear o actualizar un encargo editorial y evaluar suficiencia documental.
  6. Generar el encargo de redacción y revisar el Markdown antes de incorporarlo al sitio.

Guardar, sincronizar y recuperar

Aplicar cambios actualiza la memoria de la pestaña. Guardar persiste en JSON y crea un backup. Después, el control de sincronización compara automáticamente la base guardada con la proyección pública y solo se habilita cuando detecta uno o más macroeventos nuevos. Al pulsarlo, conserva los estados editoriales, muestra el alcance, pide confirmación y crea otro respaldo antes de escribir. Las simples actualizaciones de procesos existentes no habilitan el botón. No ejecuta Git ni publica en Internet. Si el servidor se desconecta, mantené la pestaña abierta, reiniciá npm run start y volvé a guardar.

Cambios principales de la versión instalada

  • Expedientes reproduce el estado público efectivo usado por el sitio.
  • Las publicaciones relacionadas tienen prioridad sobre el estado base del expediente.
  • La consulta es de solo lectura y no modifica macroeventos ni publicaciones.
  • Expedientes y Encargos editoriales permanecen como funciones separadas.
